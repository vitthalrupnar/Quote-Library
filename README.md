# Quote-Library
Responsive Quote App

The Responsive Quote App is a simple yet engaging web application built using HTML, CSS, and JavaScript. It dynamically displays inspirational quotes to motivate users and refresh their minds. The app is designed with a mobile-first approach, ensuring smooth usability across all devices, from smartphones to desktops.

✨ Key Features:

📜 Displays random inspirational quotes.

🔄 "New Quote" button to fetch a fresh quote instantly.

📱 Fully responsive design for seamless viewing on any screen size.

🎨 Clean and modern UI using CSS styling.

⚡ Lightweight and fast with vanilla JavaScript.

🔧 Tech Stack:

Frontend: HTML, CSS, JavaScript

Responsive Design: Media queries & flexbox

This project demonstrates core frontend development skills like DOM manipulation, responsive design, and user interactivity, making it a great addition to a web development portfolio.
